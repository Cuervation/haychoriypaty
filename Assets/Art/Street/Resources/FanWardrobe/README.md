# Fan wardrobe — Floresta

15 original transparent PNG garment references in a consistent outlined 2D cartoon style. Nine monochrome/neutral styles inspired a new set of complete front and walking All Boys fan sprites; the loose shirt PNGs are never drawn as runtime overlays. Six blue/pink/bright goalkeeper looks remain inactive. Preserve all candidate PNGs/metas; these are original illustrations, not downloaded retail-product photos, and include no real club crest, sponsor, brand wordmark, player likeness, or photo.
