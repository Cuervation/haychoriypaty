# Fan wardrobe — Floresta

15 original transparent PNG garment sprites, in a consistent outlined 2D cartoon style. Each is imported as a Unity Sprite (single image, alpha transparency enabled, no mipmaps; Android RGBA32 import setting follows the project's existing sprite template). No real club crest, sponsor, brand wordmark, player likeness, or photo is included.

## Integration note

These are independent garment PNG sprites prepared for Unity. StreetView now selects clothing by customer ID and draws the matching overlay on Floresta (level 1) supporters; later levels and the existing fan atlas/poses remain unchanged. All 15 imports/loads and deterministic selection passed focused Unity checks; representative 1080×1920 Main Game-view fitting reviewed in ignored `Logs/Acceptance/Intro/wardrobe-floresta.png`. Native/device appearance is not yet checked.
