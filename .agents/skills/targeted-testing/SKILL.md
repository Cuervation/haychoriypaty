---
name: targeted-testing
description: Use after a code, scene, settings, or visual change to choose and run only the Unity checks relevant to that change.
---

Map changed files to the affected acceptance criteria. For docs, inspect only changed docs. For gameplay logic, prefer focused EditMode tests or an isolated editor check. For scene/UI changes, verify scene references and visual play behavior. For project/config changes, validate syntax/import. Run the broad milestone check only when the milestone is complete. Report skipped/unavailable checks as not verified.
