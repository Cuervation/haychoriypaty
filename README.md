# Hay Chori y Paty

Unity `6000.6.3f1`, 2D portrait Android-first street-stall game. Open this repository in the recorded Unity editor and run `Assets/Scenes/Main.unity`.

Start with the [SDD index](specs/README.md); use [continuity](specs/continuity.md) for the current checkpoint, not the full historical status log. The active game has eleven levels, fixed per-product sale prices, unlimited affordable hiring, capped attempt-local speed, persistent Mercado/Heladera and Racing+ active cooks/Mozos. The earlier two-product prototype remains historical, disabled in Main.

No additional packages are needed beyond the checked-in manifest. Use the existing Unity MCP connection and focused tests; do not launch another editor. Android APKs and private video/test evidence belong in ignored `Builds/` and `Logs/`, not Git.
